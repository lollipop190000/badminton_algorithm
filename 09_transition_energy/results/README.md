# 전체 전이별 에너지 비용

고유 실행은 `runs/<run_id>/`에 기록한다. `C_M0.parquet`, `C_M3.parquet`는 각 2,097,152개 선수별 continuing 비용을 보존한다. Terminal 비용은 별도이며 원자료는 포함하지 않는다. 모든 수치의 단위는 J/kg이다.

`n_exact`는 **복원한 상태 키에 속한 운동학 관측 수**다. 독립적으로 검증된 실제 착지 구획 수가 아니다. 원 셔틀 픽셀 관측, 보간, 높이 추정 및 fallback을 혼동하지 않는다. 실행 수치·가정·한계는 상위 REPORT를 참조한다.
