# BFMD 상태 복원 및 모든 전이의 양 선수 에너지 비용

## 1. 원인 / 하는 이유 / 개요

Issue #2에 따라 08의 전체 fallback 표를 확장하여, 관측 셔틀 궤적으로 복원 가능한 상태별 비용과 미관측 전이 추정값을 연결한다. Q·parity·8타구·16구획·0-based 상태 인코딩을 유지한다. 새로운 결과는 09 폴더에 독립 보관하며 04/05/08의 기존 결과를 교체하지 않는다.

## 2. 과정

원본 BFMD 96개 주석의 고정 해시, ShuttleSet 원본 착지/다음 접촉 대응, 새 bbox/pose 기반 운동학을 검증한다. 경기 분할은 08의 8/2/2를 유지한다. 실행은 저장소 루트에서 `python run.py transition-energy --download-missing --run-id <새 ID>`이다.

## 3. 결과

전체 비용표를 생성하기 전 코드 검증 단계이다. 완료 실행의 수치·표·상대경로 링크는 해당 실행 결과로 갱신한다. 코트 평면에 공중 셔틀을 그대로 투영하는 방법의 한계가 확인되어 높이 추정 시나리오와 측정 여부를 분리한다. 실제 대사비용·착지 정확도·최적전략은 검증하지 않았다.
