# 고정 Q 샷별 체력 민감도 모형

## 1. 원인 / 하는 이유 / 개요

기존 Q와 샷별 종료질량을 유지하면서, 현재 타구자의 즉시 득점·실점 비율에 두 선수의 누적 이동비용을 반영한다. 타구 원인 E/U를 나누는 기존 모형과 별도의 선택이다. 이 모형의 실패는 현재 타구자의 즉시 실점이며 순수 자기 실책만을 뜻하지 않는다.

스매시·하이클리어 등을 포함한 8종 샷에 a_s, β_s, γ_s를 각각 적합한다. **β_s, γ_s≥0만 적용하며 샷 사이의 배수·순서 제약은 없다.** 최종 비교는 적합 결과와 경기 bootstrap 구간을 보고 판단한다. 이동 소모량은 체력 대리지표이며 생리적 피로의 인과효과를 추정한 것으로 해석하지 않는다.

## 2. 과정

H는 현재 타구자, R은 상대다. D_H,D_R는 현재 타구 직전까지 발생한 이동비용 누적이다. 저장된 사건표의 cumulative_energy_hitter_before, cumulative_energy_receiver_before를 사용하며 현재 타구로 들어오는 이동을 포함하고 미래 이동은 포함하지 않는다. 첫 세 타 사이의 비용도 기존 기준을 유지한다. D_*는 기존 strict train에서 정한 공통 정규화 척도로 고정하며 최대체력이 아니다.

상태 i는 최근 3타구의 16구획 패턴, r=1은 A 타구, r=0은 B 타구다. 기준표의 고정 A 관점 w0,l0를 타구자 관점 W0,L0로 변환한다.

\[
d_H=D_H/D_*,\quad d_R=D_R/D_*,\quad T=W_0+L_0,
\]

\[
z=\log(W_0/L_0)+a_s-\beta_s d_H+\gamma_s d_R,
\qquad W=T\sigma(z),\quad L=T[1-\sigma(z)].
\]

r=1이면 w=W,l=L이고 r=0이면 w=L,l=W다. 기존 Q 배열은 그대로 조회한다. 모든 샷의 w+l+Σ_j Q를 더하면 1이다. a=β=γ=0이면 기준값을 복원한다. 양의 평활 W0,L0를 사용하며 구조적 T=0은 W=L=0으로 처리한다.

피팅 표본은 경기별 마지막 타구 중 상태·샷·누적량·선수/승자 표지가 유효하고 프레임 순서 검사를 통과한 행이다. y는 현재 타자가 실제 랠리 승자이면 1이다. E/U 원인 라벨이나 fit_strict/proxy 라벨은 이 새 모형의 표본 선택·정답에 사용하지 않는다. 마지막 샷에서 종료한 타구만 학습하므로 종료 조건부 확률을 추정한다.

경기별 train/validation/test를 유지한다. train 내부 경기 5-fold로 기본 승패 odds를 교차 적합하고, train에서 계수를 적합하며 validation에서 ridge를 선택한다. test는 선택 완료 뒤 동결 평가한다. 배포 모형은 train+validation의 경기 교차 적합으로 재적합하고 baseline_final의 Q/C를 사용한다. 시험 결과에는 baseline_train을 사용한다. 기존 history/평활 hyperparameter, 비용과 누적량 대체 기준은 고정한다.

목적함수는 평균 종료 조건부 binary log loss와 ridge다. 각 샷의 a,β,γ가 각 계수의 공통 평균에서 벗어나는 정도를 같은 가중치로 벌점화하여 작은 샷 표본을 더 강하게 수축한다. 기울기의 공통 크기에도 약한 벌점을 적용해 H/R 입력의 높은 상관에서 발산을 억제한다. 기존 odds 그대로인 original, 샷별 절편만인 intercept, 공통 체력 기울기인 common을 같은 표본으로 비교한다. 최종 가족은 사용자가 지정한 shot이며 비교 결과로 자동 교체하지 않는다.

경기 bootstrap은 배포 모형과 교차 적합 기준 odds를 재적합한다. 비용표·누적량·D_*·모형 선택은 고정하므로 구간은 그 조건에 의존한다. 샷별 소모량 상관, 설계 조건수, 경계 계수 비율과 β_smash−β_high_clear 구간을 보고한다. β_high_clear가 0에 가까우면 배수를 안정적으로 해석할 수 없으므로 차이를 주로 보고한다.

의존 주제는 01 사건·분할, 04의 기준표와 05의 기존 누적비용이다. 현재 실행은 기존 직선 이동비용 정의를 사용한다. 08 BFMD의 다른 비용을 사용하려면 입력 누적량부터 새로 만들고 별도 run으로 적합한다. 이번 실행에서 BFMD 비용으로 피팅했다고 표현하지 않는다.

저장소 루트에서 실행한다.

```powershell
python run.py fixed-q --run-id 20261014-fixed-q-shot-xpinion0415 --bootstrap 200 --mc-samples 20000 --seed 42
```

새 실행은 고유 run-id를 지정한다. 이미 동결 평가가 기록된 run에서 피팅을 반복하지 않는다. fit/value/report 단계는 --stage로 나눌 수 있다. 입력은 기존 event_energy_table.parquet, baseline_train/final.npz이며 출력은 results/runs/<run-id>/다. .runtime의 코드를 직접 수정하지 않는다.

FixedQTransition은 기준 Q/C를 보존하고 새 w,l을 반환한다. 예산별 V는 기존 고정 비용 희소 연산자를 재사용하되 각 셀의 종료 승률 원천항을 새 함수로 계산한다. 모든 V는 고정 A의 승률이다. 초기 예산은 시나리오이며 종료 추가비용은 0이다. 지속 전이 뒤 비용으로 소진할 때의 경계와 동시 소진 하한/중앙/상한은 기존 가정을 유지한다. 전체 격자의 해시·로컬 위치와 재생성 방법을 기록하고 query 표를 전체 격자로 표현하지 않는다.

## 3. 결과

실제 실행 결과는 [run 보고서](../results/runs/20261014-fixed-q-shot-xpinion0415/research_report.md)에 기록한다. 계수·샷별 표본·시험 지표·bootstrap·불확실성과 Q/종료질량 보존·선수 교환·재로딩 검사, 격자/Monte Carlo 검증은 해당 run 안의 원본 파일로 연결한다.

기존 E/U 모형의 M0 선택과 결과 파일은 보존한다. 새 모형의 조건부 log loss를 E/U/C 3사건 log loss와 같은 지표로 직접 비교하지 않는다. 새 예산 V는 새 w로 재계산하며 기존 격자를 새 결과로 재사용하지 않는다.
