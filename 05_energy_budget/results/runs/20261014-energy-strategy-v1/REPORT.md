# 에너지 타구·구획 전략 실행 결과

## 1. 원인 / 하는 이유 / 개요

고정 정책의 V를 행동 선택으로 확장해 incoming 구획별 타구·목표 구획을 추천한다.

## 2. 과정

- 계속되는 타구가 선택한 구획에 도착한다고 가정합니다. 목표 정확도는 추정하지 않았습니다.
- 종료확률은 타구별이며 목표 구획별 성공·실수 효과는 추정하지 않았습니다.
- 상대는 기록된 대응 분포를 따릅니다. 예산은 생리학적 최대 체력이 아닌 시나리오입니다.
- 비용은 이동에너지 대리값이며 실제 경기 승률·대사 비용·피로 인과효과의 검증이 아닙니다.
- BFMD 비용은 거리·역할·타구 fallback이며 가감속·방향전환 계수는 가설입니다.

`scripts/run_energy_strategy.py --run-id 20261014-energy-strategy-v1`

입력·코드 해시와 고정 검증 질의는 [RUN.json](RUN.json), [protocol](protocol.json)에 있다.

### 검증 범위와 완전한 결과

5개 비용 모형 × 양 선수, 고정 질의 40개에 각각 MC 20,000회를 적용했다. 최대 Bellman 잔차 9.99436e-12, 최대 격자 차이 0.019922, 최대 MC 95% 구간 밖 오차 0.000977로 모두 기준을 통과했다. 실제 경기 승률·대사 비용·피로 인과효과 검증은 아니다.

전체 행동 점수 15,728,640행은 각 전략 선수의 차례 4,096개 패턴 × 128행동 × 양 선수 × 3개 공통 예산 × 5개 비용 모형을 모두 포함한다. 큰 격자는 각 전략에 대해 교대 포함 8,192개 상태를 보존한다. 추천 변화율은 이 상태들을 균등 가중한 비교이며 관측 경기에서의 행동 빈도가 아니다. 정책 비교 표는 선수별 4개 질의를 동등 가중한 모형 rollout 평균이다.

BFMD 비용은 기존 parity 거리 표에 조건부 추정을 연결한 동결 lookup이다. 기존 역할 통합 거리 비용과의 차이는 경로 비용뿐 아니라 비용 추정 방식·조건부 거리 prior의 차이도 포함한다. 가감속·방향전환 계수는 피팅되지 않은 가설이다. 비용별 replay 백분위수는 프레임 유효 train 전체와 감사된 대체 소비량을 포함하며, 공통 예산의 기존 완전 관측 모집단과 구분한다.

CQL 비교는 strict 적격 test 기록 상태에서 수행한 추천 일치 비교다. CQL Q를 승률로 바꾸지 않고, 목표 구획 전략의 실제 효과를 OPE로 검증했다고 표현하지 않는다. [비교 요약](cql_comparison_summary.csv), [전체 비교](cql_comparison.parquet), [추천 변화율](recommendation_change_rates.csv), [비용별 백분위수](cost_specific_budgets.csv), [예산 척도별 비교](normalized_budget_comparison.csv).

실행 코드는 기준 commit과 미커밋 변경의 조합이었다. 실제 실행 파일 SHA256와 [source_snapshot](source_snapshot)을 보존했다. 입력·checkpoint를 다시 감사했다고 주장하지 않는다. 이번 완료 과정에서는 입력 해시 유지와 새 산출물·실행 경로만 확인했다.

### 구현·게시 경로 검증

[검증 기록](delivery_validation.json), [현행 테스트 로그](publication_tests.txt), [실제 히트맵 화면](figures/browser_heatmap.jpg). 큰 격자는 로컬에 보존하고 이 컴퓨터의 게시 실행 환경에서는 같은 격자를 읽기용 링크로 연결했다. 새 clone은 large_artifacts.json의 새 실행 ID 명령으로 재생성한다. GitHub push는 수행하지 않았다.
