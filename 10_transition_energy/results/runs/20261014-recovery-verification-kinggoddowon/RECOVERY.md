# 중단된 작업 복구 기록

기존 결과를 다시 생성하지 않고 보존된 파일을 검증하여 게시를 재개했다. 최초 읽기 전용 조사 후 코드·결과·미커밋 수정의 복구 체크포인트를 별도 보존했다.

- 보존 파일 전체 목록: preserved_file_inventory.csv (재개 직전 경로·크기·SHA256).
- 계산 실행 로그: final-v2.log에 완전 표 생성과 정상 감사 결과가 남았다. 연구 82개 및 협업 검사 6개 통과 로그도 보존돼 있었다.
- 로컬 최종 커밋은 e725ce9, 당시 미커밋 파일은 REPORT.md, 원 실행 RUN.json, manifest, verification.txt 및 protected_inputs_unchanged.json이었다.
- GitHub에는 533672a45af9add2d507a6a954ace7b923460930 코드 커밋이 존재하지만, 09-complete-costs 브랜치는 3bd88836c3afa2db7b229ba7784cefede2407ff2를 가리켰고 비용표 변경 및 PR이 연결되지 않았다.
- 마지막 파일 흔적은 publish_provenance.py와 upload_files.json이다. 게시 출처 기록 및 GitHub 업로드 정리 단계까지 진행됐다는 근거다. 마지막 실행 명령의 원문, 종료 상태, 연결 해제 오류 로그는 확보되지 않았다. 업로드 지연 또는 연결 해제를 확정 원인으로 단정하지 않는다.
- 09_cost_transfer_method는 다른 연구자가 먼저 main에 반영한 주제다. 기존 로컬 작업의 10_transition_energy 정리를 유지해 번호 충돌을 피했다.
- 재개 중 main 3c195ea의 05번 고정 Q 체력 모형을 병합했다. 목차·manifest만 충돌했고 양쪽 주제를 보존했다.
- 완전 비용표 각각 2,097,152행 및 terminal lookup 131,072행을 전수 검사했다. 기존 결과 42개의 기록 해시가 모두 맞고 기존 01~09번 파일 374개가 최신 main과 동일하다.
- 최신 main 반영 후 연구 89개 및 협업 검사 6개 통과. 원 실행의 82개 통과 기록은 당시 기록으로 그대로 보존한다.
- 남은 과학적 검증: 독립 실제 착지/3D 좌표, 8종 타구 대사 실측, 경기 비용 보정. 이번 복구 검사는 파일 무결성과 계산 계약을 확인하며 이 검증들을 대신하지 않는다.
