# 12. 11번 소모량으로 고정 Q 종료 승패 재적합

## 1. 원인 / 하는 이유 / 개요

[11번의 이동거리 전달 모형](../11_integrated_transition_energy/REPORT.md)을 [01의 통합 타구 CSV](../01_data_16zone/results/processed/merged_elite_QF_SF_F.csv)에 직접 적용해, 직선 이동 소모량 대신 새 소모량으로 종료 득점·실점의 배분을 다시 적합한다. 11의 대표 모형 M0_v2를 주 결과로 보고하고 M3_v2를 민감도 비교로 둔다. 두 모형 모두 11의 타구 비용 시나리오를 사용한다.

## 2. 과정

같은 선수의 연속 타구 위치와 프레임 차이/30으로 11의 고정 전달 모형을 실행한다. 타구 직전 누적값에는 **직전 샷을 친 선수의 타구 비용과 이후 양 선수의 이동비용**까지 더하고 현재 샷 비용은 넣지 않는다. 첫 관측 타구는 0으로 두며, 앞 3타 사이의 이동도 포함한다. 11의 범위 밖인 서브에는 타구 비용을 부과하지 않고 M3 비교에서도 해당 구간 이동은 M0로 계산한다. 위치·시간 결측 대체와 학습 범위 밖 입력을 행 단위로 표시한다. 타구 시점 사이 실제 경로를 관측한 값은 아니다.

종료 확률 `w_0+l_0`, 기존 `Q`, 종료 타구 표본과 경기 분할, 기준 odds, 정규화 척도 `D_*`를 앞선 고정 Q 실험과 동일하게 둔다. 샷별 절편·양 선수의 체력 기울기는 **학습 로그손실만** 최소화한다. 기울기 비음수 외에 샷 간 배수·순서 제약은 없다. 검증·시험 결과는 설정 선택이나 재적합에 쓰지 않는다. 시험은 기존에 평가했던 분할의 재사용이며 새로운 독립 재현이 아니다. 경기 단위 paired bootstrap은 계수와 비용을 고정한 시험 손실 차이를 요약한다.

```powershell
python 12_integrated_stamina_refit/code/src/integrated_stamina_refit.py --run-id 20261104-integrated-cost-fixed-q-refit
```

누적값은 랠리 첫 타구를 기준으로 한 **추정 소모량**이다. 이전 랠리의 피로, 회복, 시작 체력이나 남은 생리적 체력을 추정하지 않는다.

## 3. 결과

통합 CSV의 91경기·5,888랠리·63,410타구에 두 선수의 타구 직전 소모량을 붙였다. 11번이 이전에 게시한 선수별 구간 79,096건을 모두 대조했으며, M0/M3 이동비용의 최대 절대 차이는 각각 4.27e-14 J/kg 미만이다. 기존과 동일한 종료 표본 3,392/753/816개로 학습/검증/시험했다. 시험 표본의 Q는 원본에서 그대로 조회했고, 두 새 모형의 `w+l` 보존 오차는 최대 1.39e-17이다.

| 모형 | 학습 로그손실 | 검증 로그손실 | 시험 로그손실 |
| --- | ---: | ---: | ---: |
| 체력 항 없이 샷별 절편만 적합 | 0.563662 | 0.538058 | **0.561224** |
| 기존 직선 소모량, 벌점 0 | 0.560875 | 0.536121 | 0.565331 |
| **11번 M0_v2 + 이전 타구 비용, 벌점 0** | 0.560658 | 0.536086 | 0.565299 |
| 11번 M3_v2 + 이전 타구 비용, 벌점 0 | 0.560310 | 0.536791 | 0.565952 |

M0의 시험 로그손실 차이(새 모형−기준)는 기존 직선 모형 대비 −0.000032(경기 bootstrap 95% 구간 [−0.000799, 0.000894]), 체력 항 없는 절편 모형 대비 +0.004075([−0.000889, 0.009857])다. 둘 다 0을 포함해 새 소모량이 시험 예측을 개선했다고 결론 내리지 않는다. M0의 자기 소모 민감도 점추정은 스매시 2.022, 하이클리어 0.725다. 이 실험은 그 차이의 신뢰구간을 산출하지 않았다.
